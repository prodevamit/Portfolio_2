# Amit Halder | Portfolio

A polished personal portfolio landing page built with HTML, CSS, and JavaScript. The site is designed to showcase a developer's work, experience, and contact information in a modern, responsive layout.

## Overview

This project is a single-page portfolio website with:

- A strong hero section and introductory copy
- Selected work/project cards
- An about section with skills and timeline
- Contact information and social links
- Dark/light theme toggle
- Smooth scrolling and subtle motion effects
- Responsive layout for mobile, tablet, and desktop screens

## Live Preview

You can view the page locally by opening `index.html` in a browser.

For a better local preview with a proper web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- Responsive landing page design
- Project showcase section
- Personal bio and experience timeline
- Contact CTA with email copy button
- Animated section reveals and scroll progress bar
- Accessible navigation and semantic HTML structure
- Clean, modern typography and visual design

## Customization

To personalize the portfolio for your own use:

1. Edit the content in `index.html`:
   - Name and intro text
   - Role and status
   - Work items and descriptions
   - About section and experience entries
   - Email and social links

2. Update styling in `styles.css`:
   - Colors and theme variables
   - Typography and spacing
   - Section layout and responsiveness

3. Adjust behavior in `script.js`:
   - Theme toggle
   - Scroll-based progress indicator
   - Reveal animation timing and effects
